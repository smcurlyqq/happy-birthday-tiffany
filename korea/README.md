# Seoul Loop — 首爾 10/17–10/20 共同計畫

五個人、五本護照（🇹🇼 🇯🇵 🇰🇷 🇭🇰 🇮🇩）的首爾四日共筆。

## 兩個東西

| | 用途 | 誰能改 |
| --- | --- | --- |
| **這個網頁** (`korea/index.html`) | 倒數、出發前檢查、五種語言、匯率換算、分帳計算 | 每個人在自己手機上；資料存在自己裝置 |
| **Notion** | 成員喜好、口袋名單投票、每日行程、記帳 | 有連結的人都能一起編輯 |

Notion：<https://www.notion.so/3d6b331a325081989f75d13d4fff3184>
（要讓朋友能編輯，在 Notion 右上 Share → 開「Anyone with the link」→ 權限選 **Can edit**）

## 網址

## 語言

介面會依瀏覽器語言自動選 中文 / 日本語 / 한국어 / English / Bahasa Indonesia，右上角也可以手動切換。

## 要改行程日期或成員國家

`index.html` 裡面：`DAYS`（四天的日期）、`SEATS`（五個國家的座位與代表色）、`RATES0`（預設匯率）。
